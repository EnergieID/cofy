The management console is where you set up and change your community's Cofy API. You need an account to log in; ask whoever hosts your Cofy for one.

After logging in you see the communities you have access to. Each community has these tabs:

| Tab | What you do there |
| --- | --- |
| Modules | Switch on the modules your community needs, and configure each one |
| Resources | Configure things several modules share, like a data source |
| Secrets | Store credentials, such as an API key, without showing them again |
| API tokens | Create the tokens other applications use to call your community's API |
| Access | Decide who else can see or change this community |

Which tabs you see depends on what you're allowed to do in that community.
