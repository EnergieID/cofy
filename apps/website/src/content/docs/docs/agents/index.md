We're working on letting AI agents help with Cofy: setting up a community through the management API, writing a settings file, or adding a source of your own.

Until then, an agent can already read these docs in one go. Point it at:

- [/llms.txt](/llms.txt): an index of the docs;
- [/llms-full.txt](/llms-full.txt): all of the docs in a single file.

With them, an agent can answer questions about modules and sources, or write the YAML for a module, a [settings file](/docs/self-host/settings-file/) or an [energy-cost tariff](/docs/energy-cost/tariffs/), for you to paste into the [console](/docs/console/modules/) or your own setup.
